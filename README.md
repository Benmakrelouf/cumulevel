# cumulevel
Weighted causal estimands for cumulative multilevel exposures: targeted learning with explicit attribution weights.
When an exposure is cumulative — educational attainment, disease stage, pack-years of tobacco — reaching a level entails having reached all the preceding ones. Dichotomising it at a target level silently attributes to that level whatever happens above it. cumulevel makes the attribution assumption an explicit parameter instead of an implicit consequence of the coding.
